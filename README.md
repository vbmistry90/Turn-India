# TURN India Website

Modern responsive website created with:
- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1

## Files
- index.html — Home page
- contact.html — Contact & Partners page
- assets/style.css — Full responsive design and animations
- assets/script.js — jQuery interactions and animations

## Run
Open `index.html` in any modern browser.

For production, replace the Unsplash image URLs with your own licensed images and connect the contact form to your backend/API.
